# Move Event Toast

Super lightweight addon that moves the Event Toast window (the popup near the top of the screen that announces level-ups, completed scenarios and similar events), with clickthrough and disable switches. Type `/moveet` in chat to open the configuration window.

## Commands

- `/moveet` — open the configuration window
- `/moveet reset` — restore every setting to the game's defaults

Any other input opens the window as well.

## The config window

- **move toast** — turn on move mode, then drag the toast spot anywhere; a green box marks its exact spot (even while no toast is showing). Closing the window leaves move mode.
- **X / Y** — move the toast spot, with boxes for exact values (or drag it in move mode)
- **clickthrough** — toasts stop intercepting mouse clicks
- **disable toasts** — no event toasts at all while set

## Compatibility

- World of Warcraft: Midnight (12.1.0)
- World of Warcraft: The War Within (11.2.7)
